## 🚀 快速开始

### 本地运行

**前置要求:** Node.js 18+

1. **安装依赖:**
   ```bash
   npm install
   ```

2. **启动开发服务器:**
   ```bash
   npm run dev
   ```
   应用将在 http://localhost:3000 运行

3. **构建生产版本:**
   ```bash
   npm run build
   ```

4. **预览生产版本:**
   ```bash
   npm run preview
   ```

---

## 🌐 部署到 GitHub Pages

本项目已配置自动部署！

### 自动部署步骤

1. **推送代码到 GitHub**
   ```bash
   git push
   ```

2. **启用 GitHub Pages**
   - 进入仓库的 `Settings` → `Pages`
   - 在 `Build and deployment` 下选择 `Source: GitHub Actions`

3. **访问你的应用**
   - 部署完成后访问：`https://hlxabcd.github.io/christmas_greetings/`
